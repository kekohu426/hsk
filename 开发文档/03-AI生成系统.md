# 03-AI生成系统

## 概述

ChineseMaster平台使用智谱AI的GLM-4模型为每个HSK词汇生成丰富的学习内容，包括快速学习、深度解析和练习材料。本文档详细说明AI生成系统的架构、Prompt设计和质量控制流程。

---

## 🎯 AI生成目标

### 词汇内容生成

为每个HSK词汇（共10500个词）生成以下3大模块的内容：

#### 1. Quick Learn（快速学习）
- ✅ **4个核心要点** (Key Points)
- ✅ **3个例句** (Examples) - 中文、拼音、英文
- ✅ **2个常见错误** (Common Mistakes) - 错误示例 + 纠正
- ✅ **2个测试题** (Quiz) - 选择题，检验理解

#### 2. Deep Dive（深度解析）
- ✅ **词源** (Etymology) - 850+字，字形演变、历史渊源
- ✅ **文化背景** (Cultural) - 600+字，文化内涵、使用场景
- ✅ **语法说明** (Grammar) - 400+字，句法结构
- ✅ **用法辨析** (Usage) - 400+字，近义词区别

#### 3. Practice（练习）
- ✅ **写作提示** (Writing Prompt) - 引导用户创作
- ✅ **发音技巧** (Pronunciation) - 声调、易错点

### 文章内容生成

- 📰 自动生成符合HSK等级的阅读文章
- 🏷️ 自动标注文章中的词汇（带HSK等级、拼音、释义）

## 📝 Prompt设计

### 核心设计原则

1. **结构化输出** - 要求AI返回严格的JSON格式
2. **明确数量要求** - 指定每部分的具体项目数和字数
3. **分层引导** - 将复杂任务拆分为明确的子任务
4. **质量标准** - 在Prompt中嵌入质量评判标准
5. **示例驱动** - 提供标准化的输出示例

请生成一个完整的JSON对象，包含以下3个部分：

### 1. quickLearn (快速学习模块)

包含4个字段：

**keyPoints** (核心要点数组，恰好4项):
- 每项50-80字
- 涵盖：字形构成、基本含义、使用场景、记忆技巧
- 语言简洁、易理解
- 针对HSK{hskLevel}学习者的水平

**examples** (例句数组，至少3项):
每项包含3个字段：
- chinese: 中文例句（使用目标词汇，10-20字）
- pinyin: 拼音（带声调标记）
- english: 英文翻译

例句要求：
- 真实、自然的语境
- 符合HSK{hskLevel}难度
- 展示词汇的不同用法

**commonMistakes** (常见错误数组，至少2项):
每项包含2个字段：
- mistake: 错误示例（标记❌）
- correction: 正确用法（标记✅）+ 简短解释

**quiz** (测试题数组，恰好2项):
每项包含3个字段：
- question: 问题（英文或中文）
- options: 4个选项的数组
- correct: 正确答案的索引（0-3）

### 2. deepDive (深度解析模块)

包含4个字段：

**etymology** (词源解析，850-1000字):
- 字形演变历史
- 甲骨文/金文/篆书到现代汉字的演变
- 字的本义和引申义
- 相关的文化历史背景

**cultural** (文化背景，600-800字):
- 这个词在中国文化中的意义
- 相关的成语、俗语、典故
- 现代使用场景和语境
- 文化内涵的演变

**grammar** (语法说明，400-500字):
- 词性详解
- 句法位置（主语/谓语/宾语）
- 搭配规则（能接什么词）
- 语法限制和注意事项

**usage** (用法辨析，400-500字):
- 与近义词的区别
- 正式/非正式场合的使用
- 口语/书面语的差异
- 地域性差异（如有）

### 3. practice (练习模块)

包含2个字段：

**writingPrompt** (写作提示，100-150字):
- 一个开放性问题或场景
- 引导学习者使用目标词汇造句或写段落
- 富有创造性和趣味性

**pronunciationTips** (发音技巧，150-200字):
- 声调重点提示
- 易错音分析
- 与相似音的对比
- 发音练习建议

## 🔧 技术实现

### GLM-4 API集成

#### 配置文件 (`backend/src/services/aiService.js`)

```javascript
import axios from 'axios';

class AIService {
  constructor() {
    this.apiKey = process.env.GLM_API_KEY;
    this.baseURL = 'https://open.bigmodel.cn/api/paas/v4';
    this.model = 'glm-4-flash'; // 或 'glm-4'

    this.client = axios.create({
      baseURL: this.baseURL,
      headers: {
        'Authorization': `Bearer ${this.apiKey}`,
        'Content-Type': 'application/json',
      },
      timeout: 60000, // 60秒超时
    });
  }

  /**
   * 为词汇生成学习内容
   */
  async generateWordContent(wordData) {
    const prompt = this.buildWordPrompt(wordData);

    try {
      const response = await this.callGLM4(prompt, {
        temperature: 0.7,
        top_p: 0.9,
        max_tokens: 4000,
      });

      // 解析JSON响应
      const content = this.parseJSONResponse(response);

      // 质量检查
      this.validateWordContent(content);

      return {
        contentJson: content,
        aiModel: 'glm-4-flash',
        wordCount: this.countChineseChars(JSON.stringify(content)),
        generatedAt: new Date(),
      };
    } catch (error) {
      console.error('AI生成失败:', error);
      throw new Error(`AI生成失败: ${error.message}`);
    }
  }

  /**
   * 调用GLM-4 API
   */
  async callGLM4(prompt, options = {}) {
    const requestBody = {
      model: this.model,
      messages: [
        {
          role: 'user',
          content: prompt,
        },
      ],
      temperature: options.temperature || 0.7,
      top_p: options.top_p || 0.9,
      max_tokens: options.max_tokens || 2000,
      stream: false,
    };

    const response = await this.client.post('/chat/completions', requestBody);

    if (!response.data?.choices?.[0]?.message?.content) {
      throw new Error('GLM-4 API响应格式错误');
    }

    return response.data.choices[0].message.content;
  }

  /**
   * 构建词汇生成Prompt
   */
  buildWordPrompt(wordData) {
    return WORD_GENERATION_PROMPT
      .replace('{word}', wordData.word)
      .replace('{pinyin}', wordData.pinyinWithTones)
      .replace('{english}', wordData.english)
      .replace(/{hskLevel}/g, wordData.hskLevel)
      .replace('{partOfSpeech}', wordData.partOfSpeech || 'unknown');
  }

  /**
   * 解析JSON响应
   */
  parseJSONResponse(response) {
    try {
      // 移除可能的markdown代码块标记
      let cleaned = response.trim();
      if (cleaned.startsWith('```json')) {
        cleaned = cleaned.slice(7);
      }
      if (cleaned.startsWith('```')) {
        cleaned = cleaned.slice(3);
      }
      if (cleaned.endsWith('```')) {
        cleaned = cleaned.slice(0, -3);
      }

      return JSON.parse(cleaned.trim());
    } catch (error) {
      console.error('JSON解析失败:', response);
      throw new Error('AI返回的内容不是有效的JSON格式');
    }
  }

  /**
   * 验证词汇内容完整性
   */
  validateWordContent(content) {
    const errors = [];

    // 检查必需字段
    if (!content.quickLearn) errors.push('缺少 quickLearn 模块');
    if (!content.deepDive) errors.push('缺少 deepDive 模块');
    if (!content.practice) errors.push('缺少 practice 模块');

    if (content.quickLearn) {
      // 检查 keyPoints
      if (!Array.isArray(content.quickLearn.keyPoints)) {
        errors.push('keyPoints 必须是数组');
      } else if (content.quickLearn.keyPoints.length !== 4) {
        errors.push(`keyPoints 应该有4项，实际有${content.quickLearn.keyPoints.length}项`);
      }

      // 检查 examples
      if (!Array.isArray(content.quickLearn.examples)) {
        errors.push('examples 必须是数组');
      } else if (content.quickLearn.examples.length < 3) {
        errors.push(`examples 至少需要3项，实际有${content.quickLearn.examples.length}项`);
      }

      // 检查 commonMistakes
      if (!Array.isArray(content.quickLearn.commonMistakes)) {
        errors.push('commonMistakes 必须是数组');
      } else if (content.quickLearn.commonMistakes.length < 2) {
        errors.push(`commonMistakes 至少需要2项，实际有${content.quickLearn.commonMistakes.length}项`);
      }

      // 检查 quiz
      if (!Array.isArray(content.quickLearn.quiz)) {
        errors.push('quiz 必须是数组');
      } else if (content.quickLearn.quiz.length !== 2) {
        errors.push(`quiz 应该有2项，实际有${content.quickLearn.quiz.length}项`);
      }
    }

    if (content.deepDive) {
      // 检查字数
      const etymologyLength = content.deepDive.etymology?.length || 0;
      if (etymologyLength < 800) {
        errors.push(`etymology 字数不足：${etymologyLength} < 850`);
      }

      const culturalLength = content.deepDive.cultural?.length || 0;
      if (culturalLength < 550) {
        errors.push(`cultural 字数不足：${culturalLength} < 600`);
      }
    }

    if (errors.length > 0) {
      throw new Error(`内容质量检查失败:\n${errors.join('\n')}`);
    }

    return true;
  }

  /**
   * 统计中文字符数
   */
  countChineseChars(text) {
    const chineseRegex = /[\u4e00-\u9fa5]/g;
    const matches = text.match(chineseRegex);
    return matches ? matches.length : 0;
  }

  /**
   * 重试机制（处理API限流）
   */
  async withRetry(fn, maxRetries = 3, delay = 2000) {
    for (let i = 0; i < maxRetries; i++) {
      try {
        return await fn();
      } catch (error) {
        if (i === maxRetries - 1) throw error;

        // 如果是限流错误，等待后重试
        if (error.response?.status === 429) {
          console.log(`请求被限流，${delay}ms后重试 (${i + 1}/${maxRetries})`);
          await new Promise(resolve => setTimeout(resolve, delay));
          delay *= 2; // 指数退避
        } else {
          throw error;
        }
      }
    }
  }

  /**
   * 生成文章内容
   */
  async generateArticleContent(topic, hskLevel, category) {
    const prompt = ARTICLE_GENERATION_PROMPT
      .replace('{topic}', topic)
      .replace(/{hskLevel}/g, hskLevel)
      .replace('{category}', category);

    const content = await this.callGLM4(prompt, {
      temperature: 0.8,
      max_tokens: 2000,
    });

    return {
      content: content.trim(),
      wordCount: this.countChineseChars(content),
    };
  }

  /**
   * 标注文章中的词汇
   */
  async annotateArticle(text, wordDatabase) {
    // 使用 jieba 或其他分词工具分词
    const words = await this.segmentText(text);

    // 从数据库匹配词汇
    const annotatedWords = [];
    let annotatedHtml = text;

    for (const word of words) {
      const wordEntry = await wordDatabase.findByWord(word);
      if (wordEntry) {
        annotatedWords.push(wordEntry);

        // 生成HTML标注
        const annotation = `<span class="word-item hsk-${wordEntry.hskLevel}" ` +
          `data-word="${wordEntry.word}" ` +
          `data-pinyin="${wordEntry.pinyinWithTones}" ` +
          `data-meaning="${wordEntry.english}">${wordEntry.word}</span>`;

        annotatedHtml = annotatedHtml.replace(
          new RegExp(word, 'g'),
          annotation
        );
      }
    }

    // 统计HSK分布
    const distribution = {};
    for (let i = 1; i <= 6; i++) {
      distribution[`HSK${i}`] = annotatedWords.filter(
        w => w.hskLevel === i
      ).length;
    }

    return {
      annotatedHtml,
      wordDistribution: distribution,
      totalWords: annotatedWords.length,
    };
  }
}

export default new AIService();
```

## ⚙️ Worker进程实现

### 词汇生成Worker (`backend/src/workers/wordGenerationWorker.js`)

```javascript
import { Worker } from 'bullmq';
import { PrismaClient } from '@prisma/client';
import aiService from '../services/aiService.js';

const prisma = new PrismaClient();

const wordGenerationWorker = new Worker(
  'word-generation',
  async (job) => {
    const { wordId, batchId } = job.data;

    try {
      // 1. 获取词汇基础信息
      const word = await prisma.word.findUnique({
        where: { id: wordId },
      });

      if (!word) {
        throw new Error(`词汇ID ${wordId} 不存在`);
      }

      // 更新进度：开始生成
      await job.updateProgress(10);

      // 2. 调用AI生成内容
      const generatedContent = await aiService.generateWordContent({
        word: word.word,
        pinyinWithTones: word.pinyinWithTones,
        english: word.english,
        hskLevel: word.hskLevel,
        partOfSpeech: word.partOfSpeech,
      });

      await job.updateProgress(80);

      // 3. 创建WordEntry记录
      const wordEntry = await prisma.wordEntry.create({
        data: {
          wordId: word.id,
          contentJson: generatedContent.contentJson,
          aiModel: generatedContent.aiModel,
          wordCount: generatedContent.wordCount,
          status: 'DRAFT', // 管理员审核后变为PUBLISHED
        },
      });

      await job.updateProgress(100);

      return {
        success: true,
        wordEntryId: wordEntry.id,
        wordCount: generatedContent.wordCount,
      };
    } catch (error) {
      console.error(`词汇 ${wordId} 生成失败:`, error);
      throw error; // BullMQ会自动重试
    }
  },
  {
    connection: {
      host: process.env.REDIS_HOST || 'localhost',
      port: process.env.REDIS_PORT || 6379,
    },
    concurrency: 5, // 并发处理5个任务
    limiter: {
      max: 20, // 每分钟最多20个请求（避免API限流）
      duration: 60000,
    },
  }
);

// 错误处理
wordGenerationWorker.on('failed', (job, err) => {
  console.error(`任务 ${job.id} 失败:`, err);
});

// 完成处理
wordGenerationWorker.on('completed', (job, result) => {
  console.log(`任务 ${job.id} 完成:`, result);
});

export default wordGenerationWorker;
```

## 📊 批量生成流程

### 管理员触发批量生成

```javascript
// backend/src/controllers/adminController.js

import { Queue } from 'bullmq';
import { PrismaClient } from '@prisma/client';

const prisma = new PrismaClient();
const wordQueue = new Queue('word-generation', {
  connection: {
    host: process.env.REDIS_HOST,
    port: process.env.REDIS_PORT,
  },
});

export const batchGenerateWords = async (req, res) => {
  const { wordIds } = req.body; // 管理员选择的词汇ID数组

  try {
    // 创建批次记录
    const batch = await prisma.generationBatch.create({
      data: {
        type: 'WORD',
        totalJobs: wordIds.length,
        status: 'QUEUED',
      },
    });

    // 将任务加入队列
    const jobs = wordIds.map((wordId) => ({
      name: `generate-word-${wordId}`,
      data: {
        wordId,
        batchId: batch.id,
      },
      opts: {
        attempts: 3, // 失败后重试3次
        backoff: {
          type: 'exponential',
          delay: 5000, // 5秒后重试，每次翻倍
        },
      },
    }));

    await wordQueue.addBulk(jobs);

    res.json({
      success: true,
      data: {
        batchId: batch.id,
        jobCount: wordIds.length,
        estimatedTime: wordIds.length * 60, // 估算：每个词汇60秒
      },
    });
  } catch (error) {
    res.status(500).json({
      success: false,
      error: error.message,
    });
  }
};

export const getBatchProgress = async (req, res) => {
  const { batchId } = req.params;

  try {
    const batch = await prisma.generationBatch.findUnique({
      where: { id: batchId },
      include: {
        jobs: {
          orderBy: { createdAt: 'desc' },
        },
      },
    });

    const completed = batch.jobs.filter(j => j.status === 'COMPLETED').length;
    const failed = batch.jobs.filter(j => j.status === 'FAILED').length;

    res.json({
      success: true,
      data: {
        batchId: batch.id,
        status: batch.status,
        totalJobs: batch.totalJobs,
        completedJobs: completed,
        failedJobs: failed,
        progress: (completed / batch.totalJobs) * 100,
        jobs: batch.jobs,
      },
    });
  } catch (error) {
    res.status(500).json({
      success: false,
      error: error.message,
    });
  }
};

## 📈 性能优化

### 生成速度

| 模型 | 单词生成时间 | 并发数 | 10500词总时长 |
|------|-------------|-------|--------------|
| glm-4 | ~60秒 | 5 | ~35小时 |
| glm-4-flash | ~30秒 | 10 | ~8.75小时 |

### 优化策略

1. **使用glm-4-flash** - 速度快，质量略低但可接受
2. **提高并发数** - 根据API限流调整
3. **批量处理** - 分批次处理，避免超时
4. **缓存机制** - 已生成的内容不重复生成
