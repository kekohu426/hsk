# 08 - 部署配置

## 📋 模块概述

本文档提供 ChineseMaster 项目在 **Vercel** 平台的完整部署方案，包括数据库、环境变量、CI/CD自动化配置。

**部署架构**:
- **用户端**: Vercel Static Hosting（HTML/CSS/JS）
- **后端API**: Vercel Serverless Functions（Node.js + Express）
- **管理后台**: Vercel Static Hosting（React SPA）
- **数据库**: Vercel Postgres
- **Redis**: Upstash Redis
- **静态资源**: Vercel CDN

**预计部署时间**: 1-2小时

## 🗄️ 第二步：数据库配置

### 2.1 创建Vercel Postgres数据库

在Vercel Dashboard:
1. 进入项目 → Storage → Create Database
2. 选择 **Postgres**
3. 数据库名称: `chinesemaster-db`
4. 区域: 选择离用户最近的区域（如 `Singapore`）
5. 点击 **Create**

### 2.2 获取数据库连接信息

创建完成后，复制以下环境变量：
- `POSTGRES_URL`
- `POSTGRES_PRISMA_URL`
- `POSTGRES_URL_NON_POOLING`

### 2.3 本地数据库迁移

创建 `.env` 文件：

```env
# 使用Vercel提供的POSTGRES_PRISMA_URL
DATABASE_URL="postgresql://user:password@host:5432/database?pgbouncer=true&connect_timeout=15"
```

运行迁移：

```bash
# 生成Prisma Client
npx prisma generate

# 运行数据库迁移
npx prisma migrate deploy

# 运行种子脚本（可选）
node backend/src/scripts/seed.js
```

### 2.4 创建初始管理员账号

```bash
node backend/src/init-admin.js
```

记录生成的管理员账号和密码。

## 🔧 第三步：Redis配置（Upstash）

### 3.1 创建Upstash Redis

1. 访问 [Upstash](https://upstash.com/)
2. 注册/登录账号
3. 创建新数据库：
   - Name: `chinesemaster-redis`
   - Region: 选择与Vercel相同的区域
   - Type: **Regional**（免费）
4. 创建完成后，复制 `UPSTASH_REDIS_REST_URL` 和 `UPSTASH_REDIS_REST_TOKEN`

### 3.2 配置Redis连接

将Redis URL添加到环境变量：

```env
REDIS_URL="redis://:password@host:port"
```

## 🔐 第四步：环境变量配置

### 4.1 Vercel环境变量设置

在Vercel Dashboard → Settings → Environment Variables，添加以下变量：

#### 数据库配置

```env
DATABASE_URL=postgresql://...（从Vercel Postgres复制）
POSTGRES_PRISMA_URL=postgresql://...（从Vercel Postgres复制）
```

#### JWT配置

```env
JWT_SECRET=your-super-secret-jwt-key-change-this-in-production-min-32-chars
```

生成强密钥：
```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

#### AI配置（GLM-4）

```env
GLM_API_KEY=your-glm-api-key-from-zhipu-ai
GLM_API_URL=https://open.bigmodel.cn/api/paas/v4
```

获取GLM API Key:
1. 访问 [智谱AI开放平台](https://open.bigmodel.cn/)
2. 注册账号并创建API Key
3. 充值（建议先充值100元测试）

#### Redis配置

```env
REDIS_URL=redis://default:password@host:port
```

#### Node环境

```env
NODE_ENV=production
```

### 4.2 本地开发环境变量

创建 `.env.local` 文件（不提交到Git）：

```env
# 数据库
DATABASE_URL="postgresql://localhost:5432/chinesemaster?schema=public"

# JWT
JWT_SECRET="dev-secret-key-do-not-use-in-production"

# GLM-4
GLM_API_KEY="your-dev-api-key"
GLM_API_URL="https://open.bigmodel.cn/api/paas/v4"

# Redis
REDIS_URL="redis://localhost:6379"

# Node环境
```

### 5.3 后端入口文件调整

修改 `backend/src/server.js`，添加Vercel适配：

```javascript
const express = require('express');
const cors = require('cors');
const path = require('path');

const app = express();

// 中间件
app.use(cors());
app.use(express.json());
app.use(express.urlencoded({ extended: true }));

// 静态文件服务
app.use(express.static(path.join(__dirname, '../../public')));

// API路由
app.use('/api/auth', require('./routes/auth'));
app.use('/api/user', require('./routes/user'));
app.use('/api/words', require('./routes/words'));
app.use('/api/articles', require('./routes/articles'));
app.use('/api/learn', require('./routes/learn'));
app.use('/api/text', require('./routes/text'));
app.use('/api/admin', require('./routes/admin'));

// 错误处理
app.use(require('./middleware/errorHandler'));

// 健康检查端点
app.get('/api/health', (req, res) => {
  res.json({ status: 'ok', timestamp: new Date().toISOString() });
});

// Vercel Serverless导出
if (process.env.VERCEL) {
  module.exports = app;
} else {
  // 本地开发服务器
  const PORT = process.env.PORT || 3000;
  app.listen(PORT, () => {
    console.log(`Server running on http://localhost:${PORT}`);
  });
}
```

## 🔄 第七步：CI/CD自动化

### 7.1 GitHub Actions配置

创建 `.github/workflows/deploy.yml`:

```yaml
name: Deploy to Vercel

on:
  push:
    branches:
      - main
  pull_request:
    branches:
      - main

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v3

      - name: Setup Node.js
        uses: actions/setup-node@v3
        with:
          node-version: '18'
          cache: 'npm'

      - name: Install dependencies
        run: |
          npm install
          cd backend && npm install
          cd ../admin && npm install

      - name: Run tests (optional)
        run: |
          cd backend && npm test

      - name: Build admin
        run: |
          cd admin && npm run build

      - name: Deploy to Vercel
        uses: amondnet/vercel-action@v25
        with:
          vercel-token: ${{ secrets.VERCEL_TOKEN }}
          vercel-org-id: ${{ secrets.VERCEL_ORG_ID }}
          vercel-project-id: ${{ secrets.VERCEL_PROJECT_ID }}
          vercel-args: '--prod'
```

### 7.2 配置GitHub Secrets

在GitHub仓库设置中添加：

1. `VERCEL_TOKEN`: 从Vercel Account Settings → Tokens创建
2. `VERCEL_ORG_ID`: 运行 `vercel project ls` 获取
3. `VERCEL_PROJECT_ID`: 从项目 `.vercel/project.json` 获取

### 7.3 自动部署流程

提交代码后，GitHub Actions会自动：
1. 检出代码
2. 安装依赖
3. 运行测试
4. 构建前端
5. 部署到Vercel

## 🔒 第十步：安全配置

### 10.1 环境变量安全

- ✅ 永远不要在代码中硬编码密钥
- ✅ 使用Vercel环境变量管理敏感信息
- ✅ 为开发/预览/生产环境设置不同的密钥

### 10.2 API安全

在 `backend/src/middleware/security.js` 添加：

```javascript
const helmet = require('helmet');
const rateLimit = require('express-rate-limit');

// 安全头部
app.use(helmet());

// 速率限制
const limiter = rateLimit({
  windowMs: 15 * 60 * 1000, // 15分钟
  max: 100, // 限制100次请求
  message: '请求过于频繁，请稍后再试',
});

app.use('/api/', limiter);

// 登录接口特殊限制
const loginLimiter = rateLimit({
  windowMs: 15 * 60 * 1000,
  max: 5, // 15分钟内最多5次登录尝试
  message: '登录尝试过多，请15分钟后再试',
});

app.use('/api/auth/login', loginLimiter);
```

### 10.3 CORS配置

```javascript
const cors = require('cors');

const corsOptions = {
  origin: process.env.NODE_ENV === 'production'
    ? ['https://yourdomain.com', 'https://www.yourdomain.com']
    : ['http://localhost:3000', 'http://localhost:3001'],
  credentials: true,
};

app.use(cors(corsOptions));
```

### 11.3 Redis缓存策略

在 `backend/src/controllers/wordController.js`:

```javascript
const redis = require('../utils/redis');

// 缓存HSK词汇列表（1小时）
const getHSKWords = async (req, res) => {
  const { level } = req.params;
  const cacheKey = `hsk:${level}:words`;

  // 尝试从缓存获取
  const cached = await redis.get(cacheKey);
  if (cached) {
    return res.json(JSON.parse(cached));
  }

  // 从数据库查询
  const words = await prisma.wordEntry.findMany({
    where: { hskLevel: parseInt(level), status: 'PUBLISHED' },
  });

  // 写入缓存
  await redis.set(cacheKey, JSON.stringify(words), 'EX', 3600);

  res.json(words);
};
```

```javascript
const axios = require('axios');

const BASE_URL = process.env.PRODUCTION_URL || 'https://your-domain.vercel.app';

async function runTests() {
  console.log('🧪 开始冒烟测试...\n');

  const tests = [
    {
      name: '健康检查',
      fn: async () => {
        const res = await axios.get(`${BASE_URL}/api/health`);
        return res.data.status === 'ok';
      },
    },
    {
      name: 'HSK词汇API',
      fn: async () => {
        const res = await axios.get(`${BASE_URL}/api/words/hsk/1`);
        return Array.isArray(res.data) && res.data.length > 0;
      },
    },
    {
      name: '文章API',
      fn: async () => {
        const res = await axios.get(`${BASE_URL}/api/articles`);
        return Array.isArray(res.data);
      },
    },
    {
      name: '管理后台访问',
      fn: async () => {
        const res = await axios.get(`${BASE_URL}/admin/`);
        return res.status === 200;
      },
    },
  ];

  let passed = 0;
  let failed = 0;

  for (const test of tests) {
    try {
      const result = await test.fn();
      if (result) {
        console.log(`✅ ${test.name}`);
        passed++;
      } else {
        console.log(`❌ ${test.name}: 返回值不符合预期`);
        failed++;
      }
    } catch (error) {
      console.log(`❌ ${test.name}: ${error.message}`);
      failed++;
    }
  }

  console.log(`\n📊 测试结果: ${passed} 通过, ${failed} 失败`);
  process.exit(failed > 0 ? 1 : 0);
}

runTests();
```

## 🔧 故障排查

### 问题1: 数据库连接失败

**症状**: API返回500错误，日志显示数据库连接失败

**解决方案**:
1. 检查 `DATABASE_URL` 环境变量是否正确
2. 确认使用 `POSTGRES_PRISMA_URL`（带pgBouncer）
3. 检查Prisma Client是否已生成：`npx prisma generate`

### 问题2: Redis连接超时

**症状**: 任务队列无法启动

**解决方案**:
1. 检查 `REDIS_URL` 格式是否正确
2. 确认Upstash Redis在同一区域
3. 测试连接：
   ```bash
   redis-cli -u $REDIS_URL ping
   ```

### 问题3: 构建失败

**症状**: Vercel部署时构建报错

**解决方案**:
1. 检查 `package.json` 中的构建脚本
2. 确认所有依赖已安装
3. 本地运行 `npm run build:all` 测试

### 问题4: API路由404

**症状**: 访问API端点返回404

**解决方案**:
1. 检查 `vercel.json` 的路由配置
2. 确认 `api/index.js` 导出正确
3. 检查后端路由定义

### 问题5: 管理后台无法访问

**症状**: 访问 `/admin` 返回404或空白页

**解决方案**:
1. 确认 `admin/dist` 目录已生成
2. 检查 `vercel.json` 的admin路由配置
3. 确认 `admin/.env` 中的 `VITE_API_URL` 正确
