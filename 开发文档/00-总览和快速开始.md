## 🚀 快速开始

### 第一步：环境准备

**必需工具**:
- Node.js 18+
- npm 或 pnpm
- Git
- Vercel CLI（可选，用于本地测试）

**第三方服务账号**:
- Vercel账号（部署）
- 智谱AI账号（GLM-4 API Key）
- Upstash账号（Redis，任务队列）

---

### 第二步：创建项目结构

```bash
cd /Users/keko/Downloads/chinese-learning-platform

# 创建后端目录
mkdir -p api/{controllers,services,middleware,routes,utils,workers}
mkdir -p api/routes/admin
mkdir -p api/services/{ai,seo,storage}
mkdir -p api/controllers/admin

# 创建管理后台目录
mkdir -p admin/src/{pages,components,services,hooks,utils}

# 创建Prisma目录
mkdir -p prisma

# 创建公共静态文件目录
mkdir -p public/word
mkdir -p public/article
```

---

### 第三步：初始化项目

```bash
# 初始化package.json
npm init -y

# 安装核心依赖
npm install express cors bcryptjs jsonwebtoken dotenv
npm install @prisma/client
npm install axios bullmq ioredis
npm install csv-parser multer
npm install nodejieba pinyin

# 安装开发依赖
npm install -D prisma nodemon

# 初始化Prisma
npx prisma init
```

---

### 第四步：配置环境变量

创建 `.env` 文件：

```env
# 数据库
DATABASE_URL="postgresql://user:password@host:5432/chinesemaster"

# JWT密钥
JWT_SECRET="your-super-secret-jwt-key-change-this-in-production"

# GLM-4 API
GLM_API_KEY="your-glm-api-key"
GLM_API_URL="https://open.bigmodel.cn/api/paas/v4"

# Redis（Upstash）
REDIS_URL="redis://default:password@host:port"

# Node环境
NODE_ENV="development"
```

## 🔧 常见问题排查

### Q1: 数据库连接失败
**检查**:
- `.env` 中的 `DATABASE_URL` 是否正确
- 数据库是否已创建
- 网络连接是否正常

### Q2: AI生成失败
**检查**:
- GLM API Key是否有效
- Token余额是否充足
- 提示词格式是否正确

### Q3: 静态页面无法访问
**检查**:
- HTML文件是否已生成在 `public/word/` 目录
- Vercel路由配置是否正确
- 文件名是否与slug匹配

### Q4: 用户端登录失败
**检查**:
- JWT_SECRET是否设置
- API端点URL是否正确
- 浏览器控制台是否有CORS错误
